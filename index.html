RESEARCH INTERNSHIP

EEG → iEEG Signal Reconstruction

Brain Signal Processing / EEG–iEEG Research Lab · IIT Bhubaneswar

Jun 2026 — Jul 2026

Worked on machine-learning approaches for reconstructing intracranial brain signals from scalp EEG measurements.

  • Engineered synthetic paired 20-channel EEG and 12-channel iEEG datasets using latent neural source modeling and automated signal generation pipelines.
  • Developed IED and Non-IED event generation workflows with source-level signal injection and automated event-window extraction using Python and NumPy.
  • Evaluated signal realism using correlation, power spectral density and inter-subject spectral similarity.
  • Implemented and evaluated a VAE-cGAN based EEG-to-iEEG reconstruction approach using SPADE residual blocks, LSTM layers and PatchGAN.
◆ Deep Learning · Signal Processing · EEG/iEEG
